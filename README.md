# Maison Costura Recife Studio

Crie um site profissional, elegante e responsivo para o Maison da Costura, um espaço de cursos de corte e costura e modelagem de roupas, localizado em Recife, Pernambuco.



O objetivo é apresentar a marca, divulgar os cursos, informar valores e duração, detalhar o conteúdo das aulas e permitir que os interessados entrem em contato facilmente pelo WhatsApp ou visitem o endereço físico.



O projeto deve ser simples, utilizando os recursos gratuitos disponíveis na Lovable, sem banco de dados, login, área de alunos ou sistema de pagamentos online.

Paleta de cores:



- Rosa antigo: #C86B88

- Rosa delicado: #E7A1B5

Evite um visual infantil, exageradamente colorido ou poluído.
